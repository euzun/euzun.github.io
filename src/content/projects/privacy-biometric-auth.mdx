This research addresses privacy concerns in biometric authentication by enabling
server-based authentication **without storing biometric templates on remote
servers**. The project, called **Justitia**, bridges deep-learning inference
methods with privacy-preserving primitives.

![Justitia system overview](/images/projects/justitia.png)

The core innovation transforms face and voice biometric processing to work with
fuzzy extractors while maintaining accuracy. The system achieves 0.33% false
rejection at zero false acceptance on benchmark testing, with multimodal face and
voice reaching 1.32% false rejection at zero false acceptance. Security
assessments indicate approximately 25–33 bits of security depending on modality,
measured via a Generative Adversarial Network (Style-GAN)-based entropy
mechanism.

An encrypted enrollment/authentication system was implemented with Android and
Node.js front-ends and a RESTful identity provider (IdP) server compatible with
the OpenID Connect (OIDC) protocol, with a password manager built on top of the
authentication mechanism.

**Recognition.** Cybersecurity Summit poster session award ($1,000, 2019) and
CREATE-X Startup Invitation award (2018).
