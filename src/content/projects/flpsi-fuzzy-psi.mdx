This research addresses privacy concerns in biometric surveillance systems. The
project introduces a protocol that enables private queries of biometric scans
against a database while maintaining confidentiality: a querier learns only the
matching identities, while the database server gains no information about the
query.

The key innovation is **Fuzzy Labeled Private Set Intersection (FLPSI)**, which
computes the intersection of noisy input sets by considering closeness/similarity
instead of equality. The implementation integrates facial recognition with a
Hamming-space mapping, locality-sensitive hashing, secret sharing, and
post-quantum cryptography.

![FLPSI system overview](/images/projects/flpsi.png)

**Performance.** For a 10,000-row database, response time reaches 146 ms over WAN
and 47 ms on LAN, transferring 12.1 MB with 0.94 s offline precomputation. At
1 million rows, performance scales to 1.66 s (WAN) and 1.46 s (LAN). The system
improves upon prior work by 9–25× (WAN) and 1.2–4× (LAN), with a 0.75% false
non-matching rate comparable to plaintext face matching.

**Recognition.** People's Choice Award and CREATE-X Launch Invitation at the
IISP Demo Day Finale (2020).
