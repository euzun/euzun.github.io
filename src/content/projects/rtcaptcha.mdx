Facial and voice-based authentication is increasingly popular with services like
MasterCard and AliPay, but many publicly available recognition systems are
vulnerable to attacks. Recent advances in face and voice modeling enable
adversaries to create convincing synthetic media using minimal victim data.

![rtCaptcha live demo](/images/projects/rtcaptcha.gif)

The **Real-Time Captcha (rtCaptcha)** system addresses this vulnerability by
requiring users to solve a Captcha and record a video selfie while announcing the
answer. Rather than trying to distinguish real from synthesized biometrics,
security derives from **Captcha strength**. User studies demonstrated that
attackers would need to solve Captchas in under 2 seconds to appear human — an
unrealistic requirement for current attack capabilities.

The work proved the vulnerability of major MLaaS systems (e.g., Azure Cognitive
Services, Amazon Rekognition) against attacks ranging from crude copy-paste to
deep-learning synthesis, and was implemented as an Android application for user
studies and security analysis.
